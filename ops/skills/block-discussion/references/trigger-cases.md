# block-discussion 触发判例

> 职责：本技能触发的回归基线，竞争性触发验收与漂移修订以此为准。
> 真源：本技能触发判例（正判例、反判例、行为判例）
> 读取：维护读取

## 正判例（该触发，主代理真实工况）

1. 任务推进到必须用户拍板的分叉，需要产出结构化受阻讨论。
2. 子代理回执 needs_owner，主代理要把缺口整理成用户可裁决的形态。
3. 验收发现无法自行消解的矛盾，要停下来和用户对齐。

## 反判例（近失配不该触发，注明去处）

1. 普通进度汇报。 → 日常输出（无技能）。
2. 评审 findings 汇报。 → 评审产物（无技能）。
3. 可以自行消解的不确定项。 → 直接消解后继续，不升级（无技能）。

## 行为判例

1. 触发后按合同产出：事实、已尝试、可选项、要用户裁决的问题；不夹带情绪与冗余过程。
2. 用户拍板后落回任务，不重复讨论已裁决项。
