# tool-ui-design 触发判例

> 职责：本技能触发的回归基线，竞争性触发验收与漂移修订以此为准。
> 真源：本技能触发判例（正判例、反判例、行为判例）
> 读取：维护读取

## 正判例

- 「配置页看不懂，把角色介绍改成人话」：命中，先列用户名称、判断用途和显示来源。
- 「WinForms 导入窗口挤在一起、缩放就遮字」：命中，先取得窗口范围、DPI、原生控件和样稿约定。
- 「查一下这页的对齐和颜色，按钮还能用也要报」：命中，按具体位置记录对齐、可读性与已确认决定的偏离；参考值偏离作为建议。

## 反判例

- 「画一张派发链路的 HTML 解释图」：使用 visual-explainer。
- 「修改写给模型的工具 description」：使用 rule-authoring。
- 「数据库重试逻辑有 bug，界面不变」：无需本技能。

## 行为判例

- 给出角色配置数据和未确认页面需求：产出字段用途表与真实中文静态样稿，不直接交付新页面代码。
- 给出已确认样稿、授权局部对齐修复：复用样稿，修改对应布局并交付同场景对照，不重开全部设计决策。
- 给出能点击但按钮文字明显看不清的页面：记录位置、主题与对比值，作为可读性问题报告，不因主路径可用而省略。
