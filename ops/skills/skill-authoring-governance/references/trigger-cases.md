# skill-authoring-governance 触发判例

> 职责：供本技能触发与漂移修订回归使用。
> 真源：本技能的正、反与行为判例
> 读取：维护读取

## 正判例

1. 「帮我创建一个新技能。」
2. 「这个技能触发老是不准，帮我改 description。」
3. 「重写一下这个技能的资源分层。」
4. 「审查一下这个技能质量能不能收口。」
5. 「两个技能重叠了，合并归档一下。」
6. 「写个技能规程处理这类重复任务。」

## 反判例

1. 「写一份新的 policy 或 workflow 规则。」→ rule-authoring。
2. 「把整套 `AGENTS.md` 规则清洗去防御。」→ rule-corpus-cleanup。
3. 「记一条这次任务的进度笔记。」→ 一次性状态，无技能。
4. 「这个工具坏了修一下。」→ tooling-iteration。
5. 「派子代理并发把这批文件改了。」→ subagent-fleet-discipline。

## 行为判例

1. 「新建一个 X 技能。」→ 首动作：读创建规程，按治理判定扫描并确认归属。产出：八项技能合同；确需新建时判例先于正文落盘，按差异选择验证。
2. 「审查这个技能能否收口。」→ 首动作：读质量门，核对本次差异与已有证据。产出：结论、采用的证据、必须修补项；有具体证据缺口再选验收方式。
3. 「这个技能漏掉了中文触发。」→ 首动作：按漂移修订登记话术与现象。产出：分诊、受影响判例、description 修订与回归证据。
