# 技能治理判定

> 职责：判断内容归属及新建、修补、合并、归档、删除动作。
> 真源：本技能的归属与重叠处理规则
> 读取：命中读取

## 归属

先判断内容是否会改变未来同类任务的触发、首动作、执行、资源读取、验证或失败恢复，再选载体。

| 内容 | 载体 |
| --- | --- |
| 可复用的过程性规程 | 技能 |
| 稳定事实、用户偏好 | 记忆 |
| 项目规则、设计说明、运行手册 | 项目文档或入口规则 |
| 当前状态、临时待办、未验证猜测 | 状态文件、笔记或交接 |
| 原始资料镜像 | refs，作为资料而非技能入口 |

## 已有技能扫描

创建前扫描当前项目技能目录、会话可见技能和用户点名路径，寻找同任务类、总括、窄技能、过时技能及触发重叠。把扫描范围、命中对象和推荐动作合写进技能合同的「相邻技能与归属判断」，未覆盖范围如实说明。

BLOCK IF: 未扫描已有技能就新建。出口：先补扫描；授权不足时请求所需范围，保留归属建议而不创建。

## 动作判定

| 动作 | 判据与执行 |
| --- | --- |
| 新建 | 任务类可复用、边界清楚且无合适总括技能；写清相邻边界 |
| 修补 | 现有技能覆盖任务类，只缺触发、流程、验证、路由或恢复；修改现有技能 |
| 合并吸收 | 同工作流重复，或窄技能只是总括技能片段；选择总括技能吸收稳定流程，长案例下沉，记录被吸收关系 |
| 归档候选 | 已被吸收、只剩历史价值，或质量不足但可能恢复；提出证据，取得用户明确确认后执行 |
| 删除候选 | 误导、重复、无历史价值且无独特经验损失；提出证据与风险，取得用户明确确认后执行 |
| 拒收 | 内容属于其他载体；说明去处 |

常用不豁免质量要求，长期未用本身也不是归档或删除依据。

决策合入 `ops/skills/skill-authoring-governance/references/skill-authoring-model.md` 的技能合同：归属项写结论及依据，用户决策项写待确认的动作与风险，不另填治理表。
