# external-review-rescue 触发判例

> 职责：本技能触发的回归基线，竞争性触发验收与漂移修订以此为准。
> 真源：本技能触发判例（正判例、反判例、行为判例）
> 读取：维护读取

## 正判例（该触发，用户真实话术）

1. "这个卡点我拿不准，整理成任务书投给 GPT Pro 看看。"
2. "让 Deep Research 帮我把这堆官方文档和 issue 综合一下。"
3. "方案成形了但误判代价高，找个强网页模型挑反例。"
4. "用浏览器登录态的强模型审一下这个方案。"
5. "这事儿本地验证太慢，投个外援并行消缺口。"
6. "这个方案取舍请专家看一枪，Astra 和 grok 各问一次。"

## 反判例（近失配不该触发，注明去处）

2. "一条命令就能确认的版本号，帮我查一下。" → 本地短验证（无技能）。
3. "派子代理并发审这批文件。" → subagent-fleet-discipline。
4. "这个工具报错了帮我修。" → tooling-iteration。
5. "帮我把这套规则清洗瘦身。" → rule-corpus-cleanup。

## 行为判例

1. 任务提示："仿真路线成本高，参数能否区分两个假设不确定，问外援。" / 期望首动作：判外援判据 + 写完整任务书。 / 期望产出：可投递任务包（目标 / 来源 / 卡点 / 事实 / 假设 / 已尝试 / 求助 / 结果分叉 / 脱敏）+ 投递口径。
2. 任务提示："请专家判断这两个方案哪个更好，材料我都整理好了。" / 期望首动作：写自足卷宗，选 pick `consult_design`（诊断类选 `consult_diagnosis`）。 / 期望产出：`tool_contract.allowed=[]`、卷宗内联的种子，一次派发，主代理裁决。
