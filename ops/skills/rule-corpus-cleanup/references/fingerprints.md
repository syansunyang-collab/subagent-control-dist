# 病灶指纹表

> 职责：定义规则语料病灶指纹和审计判据。
> 真源：F1-F16 病灶指纹与 R 系审计判据
> 读取：命中读取

> 用途：第 0 步侦察扫描与第 3 步漏网审计的判据真源。每条含指纹（怎么认出来）、病理（为什么是病）、处置。

## §1 病灶清单

| # | 病灶 | 指纹 | 病理 | 处置 |
| --- | --- | --- | --- | --- |
| F1 | 禁令堆 | 连串「不得 / 禁止 / 不要」围着同一个该做的动作绕 | 模型从禁止句里反推该做什么，既费推理又教坏注意力；三句禁止顶不上一句祈使 | 改祈使句直接给动作；真正的硬线收进门禁标签 |
| F2 | 括号反写 | 属性、状态、限定塞在括号里，一行载三个事实 | 括号内容被当注释跳读，事实丢失；行内密度高到无法核对 | 属性拆成表格列或独立短句 |
| F3 | 软化词 | 「尽量、建议、必要时、注意、确保」无触发条件 | 无判定即无执行；模型要么忽略要么过度触发 | 补可判定触发条件，补不出就删 |
| F4 | 未定义限定词 | 「普通、复杂、大型、合理、较长」直接驱动分支 | 同 F3，且常接硬后果（强制路由、阻断） | 给可枚举判据（数量、闭集、可观察事实）或删 |
| F5 | 许愿谓词触发 | 「需求有缺口时」「给出真实目标时」这类模型无法判定的 WHEN | 触发条件不可观察，规则等于死的或随机触发 | 改为可观察触发：用户显式言语、文件内容标记、字段值 |
| F6 | 双真源 | 同一事实（表、清单、值域、流程）在两处各维护一份 | 必然漂移，漂移后两处都不可信 | 撤一侧留带语义的指针；唯一真源 |
| F7 | 复读门禁 | BLOCK / 禁止句只是上文 MUST 的逐义否定 | 零信息增量，纯噪声 | 删 |
| F8 | 外域枚举 / 受众错配 | 子代理材料里罗列「什么不归我管、归谁管」、主代理消费规则、跨能力裁决 | 读者拿着它没有任何可执行动作；路由知识属于派发方 | 删枚举，保留一条通用收口（对象不符→上报）；裁决移回派发方真源 |
| F9 | 坏例复活靶子 | 对照样例的坏例指名已废除机制、复述坏动作细节 | 把读者送回去学被废除的东西，反向塑形 | 按「坏例三不」改写或删坏例 |
| F10 | 自我指控惩罚表 | 给执行者自己列的违例编号表、自查仪式、违例登记机制 | 依赖不可观察的自我判定；把状态文件变成忏悔录；每行多半与既有门禁重复 | 整删；逐行核对残值：已有真源的标 F6 处理，已机械化的删，真增量并入对应门禁 |
| F11 | 无出口门 | BLOCK 触发后文内找不到合法后继动作 | 死锁制造机 | 补出口闭集：修正重试 / 上报 / 用户裁决 / 显式降级 |
| F12 | 悬空引用 | 点名的文件、字段、章节在真源中不存在 | 多为机制重构后的旧债；误导执行 | 改指现行真源，或补定义 |
| F13 | 重复确认仪式 | 同一件事在流程上下游被要求向用户确认两次以上 | 打断用户两次，第二次确认没有新信息 | 保唯一强确认点；下游只拦确认点之后新出现的风险 |
| F14 | 修辞情绪词 | 骂语、比喻、夸张作为"塑形工具" | 语义载荷可以用技术陈述等价表达；情绪是噪声 | 改技术陈述，保留其中的判定语义（如对抗性否定预设） |
| F15 | 机械可查写成文字 | 路径存在性、字段齐全、格式、枚举等让模型"注意检查" | 脚本一行能查的事不该消耗模型注意力 | 交给 lint / 校验脚本，文字只留机制位置与失败动作 |
| F16 | 本机绝对路径 | 语料中出现盘符或本机用户目录 | 语料一旦被复用或下发立即失效 | 改相对路径或占位符；有 lint 的加一类检查 |

## §2 结构判据（R 系，审计员用）

本表是通用扫描判据的独立副本，供目标语料不在本仓（外部 `CLAUDE.md`、提示词库等）时使用；目标语料是本仓或装有本控制面模板的仓库时，判据以 `ops/skills/rule-authoring/SKILL.md` §2 为真源，本表不再适用。

判定单位是动作语义不是词面；豁免必须是写出来的字；「跑了没出事」不构成通过。

| # | 判据 | 级别 |
| --- | --- | --- |
| R1 | 自举悖论：解除某条 BLOCK 所必需的动作被该条或同域另一条 BLOCK 禁止 | FAIL |
| R2 | 义务-禁止对撞：同一情境一条 MUST 要求的动作命中一条 BLOCK | FAIL |
| R3 | 无出口门（即 F11） | FAIL |
| R4 | 锁无释放：占有类规则未显式列出释放事件集 | FAIL |
| R5 | 不可能义务：合规判定依赖不可观察或跨会话不可持久化的状态 | FAIL |
| R6 | 双向罚 × 模糊谓词：做与不做都设违例且谓词无可枚举判据 | FAIL |
| R7 | BLOCK 复读 MUST（即 F7） | WARN |
| R8 | 悬空引用（即 F12） | FAIL |
| R9 | 双真源（即 F6） | FAIL |
| R10 | 模糊谓词接硬后果（即 F4 接 BLOCK / 强制路由） | FAIL |
| R11 | 坏例复活靶子（即 F9） | FAIL |
| R12 | 禁令堆塑形（即 F1），或门禁约束以散文落在标签外 | WARN |

## §3 扫描提示

- 指纹可 grep 的先 grep：「不得.*不得」「必要时」「（.*git.*）」类正则粗筛，再人工判读。
- F5 / F8 / F10 / F13 是语义病，grep 只能找候选，判定必须读上下文。
- 扫描产物按「文件 × 病灶 × 处数」列分布图，按病灶密度排批次优先级。
