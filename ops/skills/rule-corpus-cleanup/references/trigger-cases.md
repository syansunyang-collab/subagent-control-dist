# rule-corpus-cleanup 触发判例

> 职责：本技能触发的回归基线，竞争性触发验收与漂移修订以此为准。
> 真源：本技能触发判例（正判例、反判例、行为判例）
> 读取：维护读取

## 正判例（该触发，用户真实话术）

1. "我的 `AGENTS.md` 太长太乱了，帮我清洗瘦身。"
2. "这套 CLAUDE.md 规则互相矛盾，代理被卡死变怂，治理一下。"
3. "提示词库臃肿，去过度防御。"
4. "帮我审计并重写这一整套代理规则。"
5. "规则里全是禁令堆，精简掉。"
6. "这套 workflow 和 policy 攒了一堆自查仪式，瘦一瘦。"

## 反判例（近失配不该触发，注明去处）

1. "改一下 `AGENTS.md` 第 5 节这一句。" → writing-governance 或单文件小修（无技能层触发）。
2. "写一份新的 policy 文件。" → writing-governance。
3. "创建一个新技能。" → skill-authoring-governance。
4. "重构一下业务代码。" → 代码重构（无技能）。
5. "把这个规则质量问题投给外部模型审。" → external-review-rescue。

## 行为判例

1. 任务提示："`AGENTS.md` 加整套治理规则做去防御清洗。" / 期望首动作：第 0 步侦察，读 fingerprints 病灶指纹表做 grep 级扫描。 / 期望产出：病灶分布图 + 清洗方案交用户拍板。
2. 任务提示："这套提示词库瘦身。" / 期望首动作：侦察 + 立宪（缺写作标准则拷入 constitution-template）。 / 期望产出：写作宪法 + 按文件不相交切片的批量整修计划。
