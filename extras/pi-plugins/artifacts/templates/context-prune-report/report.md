## 五、运行账：输入、输出、缓存与裁剪

$ledger_scope

### 主模型的输入、输出和上下文

- **累计输入**：每次请求送入的内容相加。同一段历史反复发送，会反复计数。
- **输入峰值**：单次请求最多携带多少内容，反映上下文压力。
- **缓存读占比**：输入 token 中复用缓存的比例。缓存内容仍占上下文；命中缓存只减少重新计算及相应费用。
- **输出**：模型生成的 token 数，以服务端用量记录为准。

$traffic

### 裁剪做了什么

**替换结果数**是被缩减过的不同工具结果数量；**摘要次数**是摘要模型的调用次数。一次摘要可处理多个结果，二者不能等同，也不能直接换算成节约了多少 token。**原文回查**是裁剪后重新读取归档原文。

$pruning
