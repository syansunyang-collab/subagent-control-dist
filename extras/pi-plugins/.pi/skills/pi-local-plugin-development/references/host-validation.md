# 宿主验证与本地切换

> 职责：验证插件在实际 Pi 宿主中的行为并完成可恢复的安装替换。
> 真源：当前安装版文档、实际加载实现、项目测试和宿主现场证据
> 读取：隔离测试、Windows 或 Pi Web 适配、本地安装及卸载时

## 定位入口

通过当前 Pi 可执行文件定位安装包目录，从 package.json 取得版本；读取该版本的 docs/extensions.md、docs/packages.md 及命中功能的官方 examples/extensions 示例。涉及 SDK 或 RPC 时再读对应文档与直接实现。联网核对官方当前文档与上游变更，记录与本机版本的差异。

从 settings.json 的 packages、extensions 和默认扩展目录确认加载来源，只输出需要的非敏感字段。区分仓内源码、本地安装包及已加载的进程。配置存在不能证明代码已经加载。

## 分层验收

| 路径 | 最小证据 | 不能替代的结论 |
| --- | --- | --- |
| 注册入口 | 实际加载器成功注册，工具名和 schema 可见 | 不证明业务功能完成 |
| 核心状态 | 针对本次改动运行包内测试，覆盖取消、更新和错误的实际分支 | 模拟宿主不等于真实宿主 |
| 生命周期 | 在隔离会话验证启动、忙闲、结束和重新加载后的资源状态 | 磁盘修改不等于旧进程已更新 |
| Windows 命令 | 使用真实配置的 shellPath 执行无副作用命令并检查超时和输出 | mock 参数传递不等于命令可运行 |
| RPC / Pi Web | 实际工具调用、消息投递及会话恢复证据 | 终端界面成功不等于网页可用 |
| 并发与恢复 | 有共享状态时用独立进程竞争，并检查中断后的领取和任务状态 | 同一进程 Promise 并发不等于多进程互斥 |
| 异步事件 | 连续到期、忙时投递、取消后消费及最新状态检查 | 提交消息不等于消息已消费 |

按改动和实际使用入口选择行，不把整表变成所有插件的固定测试套餐。明确涉及的路径才执行。复用现有测试和有效结果。

使用临时状态目录和无副作用夹具，记录运行前后宿主配置差异。纯加载检查无需请求远端模型；只有模型行为验证才发起受控请求。需要 RPC 隔离与配置安全时走 use-pi-rpc-safely 技能；查看其可见入口定位正文。

## Windows 与网页宿主

通过宿主支持的配置接口取得 shellPath；使用 SDK 解析结果或已核对的等价实现，避免把开发机 PATH 当作运行前提。命令取消、超时和进程树退出按实际执行方式验证。

读取目标网页宿主的会话空闲回收与保活实现。仅在插件确实持有待办时保活，完成、取消和会话结束后释放。区分同进程注册与跨进程租约；按真实部署边界取证。重载或切换会话时检查旧闭包、定时器和监听器是否停止。

## 安装、替换与恢复

1. 明确本次授权是开发、临时加载还是持久安装。用户只要求评估或翻译时保持运行环境不变。
2. 保留旧配置相关字段和持久状态的可恢复副本，检查活跃任务及已进入宿主队列的消息。迁移先预览，明确哪些任务继续、暂停或跳过。
3. 通过本机文档支持的本地包安装入口接线，将依赖声明留在自维护源码包中。直接编辑已安装第三方 node_modules 不作为长期交付方式。
4. 替换同一能力时停止旧执行源，核对新实例实际工具清单和调用路径。卸载磁盘包不等于已运行实例立即忘记其工具；按宿主支持的重载或重启入口验证生效。
5. 按用户结果做一次最小端到端验收。失败时撤回本次安装接线和新实例，恢复已保留的配置；已产生的外部副作用单独说明，不承诺由文件回退自动撤销。

交付报告分别说明源码完成、测试通过、安装完成及当前实例生效情况。时间不足时提交可恢复的候选版并说明缺口，保留仍可工作的环境。
