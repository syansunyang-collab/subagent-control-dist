## 核查
- [x] 核对生产来源、请求钩子和重载复现。

## 实现
- [x] 成功响应后持久化已读结果，按当前分支恢复。

## 验证
- [x] 覆盖失败、未读、分支、压缩、回执和重复保存。
- [x] 本地提交，经现有入口部署并验证加载。

部署版本 `1.6.0-local.9-3cb018f`，80 项离线测试通过。Pi 0.87.1 正式 SDK 与 provider 的本地模拟对照通过，旧版重载后工具输出为 2,433 字符，新版为 1,635 字符；两组均 2 请求，无网络或真实凭据。部署后的固定路径安装包复验通过，Pi Web 目标会话已重新初始化并保持空闲。全局设置及策略配置哈希未变。真实任务费用与整体缓存回退收益另行验收。

只保存发送边界可确认的工具结果 ID，追加为模型不可见的会话记录。没有记录的历史结果仍需先读一次，不从旧对话推断全部已读。已有回执、当前分支可见性、最近两轮及受保护结果沿用现有规则。缓存总体收益与该重载修复分别验收。
